**Trade Winds is in free public beta.** A 20-chapter Caribbean crime story you fly yourself in Microsoft Flight Simulator.

### Install
1. Download **TradeWinds-Setup-….exe** below and run it.
2. Windows may show "Windows protected your PC" because the beta isn't code-signed yet. Click **More info → Run anyway**.
3. Start MSFS 2024 (or 2020), load into any airport, then open Trade Winds. It connects to the sim by itself.

The app updates the game automatically. You only need a new installer when a release here says so.

### Needs
- Windows 10 or 11, Microsoft Flight Simulator 2024 or 2020
- No other add-ons. Any aircraft that fits a chapter's role works, including payware.

### Found a bug or have feedback?
- In the app: **Hangar → Saves & help → Report a problem**, then **Open a GitHub issue**. The report is copied for you, so just paste it in.
- Or [open an issue](https://github.com/ryanbaseball761-lab/winds/issues/new/choose) directly.

### Privacy
Saves stay on your PC (Documents\Trade Winds). The app contacts GitHub (game updates and character art), Google Fonts, and the US National Hurricane Center (real storms). OpenAI is contacted only if you add your own key for premium voices.

### Known in this beta
- The in-sim toolbar panel isn't included yet. Play from the app window or the phone companion.
- MSFS doesn't let add-ons set the weather, so briefings follow the sim's live weather.
